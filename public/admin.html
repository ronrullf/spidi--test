🔌 API de Webhooks para Apps Externas Conecta tu e-commerce, CRM, bot o POS externo

Cualquier aplicación externa puede enviar un webhook HTTP POST a este sistema para generar links de pago automáticamente especificando el monto en Bolívares o USD.

POST /api/webhooks/incoming
Ejemplo de Payload JSON que recibe el Webhook:
{ "action": "create_payment_link", "amount_bs": 25.00, "concept": "Cobro desde App Externa", "client_name": "Juan Pérez", "client_phone": "584141234567" }
Ejemplo de cURL para desarrolladores:
curl -X POST "http://localhost:3000/api/webhooks/incoming" \ -H "Content-Type: application/json" \ -d '{"action":"create_payment_link","amount_bs":25.00,"concept":"Venta POS"}'
